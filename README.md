# URL Shortener App 🔗

A modern, full-stack URL shortener application built with Express.js and React.

## Features

✨ **Key Features:**
- **Create shortened URLs** - Convert long URLs into compact, shareable links
- **View history** - See all your shortened URLs in a clean list
- **Copy to clipboard** - Easily copy shortened URLs with one click
- **Click tracking** - Track how many times each shortened URL has been visited
- **Beautiful UI** - Modern gradient design with smooth animations
- **Responsive** - Works seamlessly on desktop and mobile devices
- **Fast redirection** - Instant redirects to original URLs

## API Endpoints

### Create a shortened URL
```
POST /api/shorten
Content-Type: application/json

{
  "longUrl": "https://example.com/very/long/url"
}

Response: {
  "shortId": "abc123xy",
  "longUrl": "https://example.com/very/long/url",
  "createdAt": "2026-09-07T11:51:16.216Z",
  "clicks": 0
}
```

### Get all shortened URLs
```
GET /api/list

Response: [
  {
    "shortId": "abc123xy",
    "longUrl": "https://example.com/very/long/url",
    "createdAt": "2026-09-07T11:51:16.216Z",
    "clicks": 0
  }
]
```

### Redirect to original URL
```
GET /:shortId

Redirects to the original long URL
```

### Health check
```
GET /api/health

Response: { "status": "OK" }
```

## Installation & Usage

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Development

1. **Install dependencies:**
   ```bash
   npm install
   cd client && npm install
   ```

2. **Run both servers:**
   ```bash
   npm run dev
   ```
   This will start:
   - Backend API on port 5000
   - Frontend dev server on port 3000

3. **Or run servers separately:**
   ```bash
   # Terminal 1 - Backend
   npm run server

   # Terminal 2 - Frontend
   npm run client
   ```

### Production Build

```bash
npm run build
# Frontend will be built to client/dist/
```

## How to Use

1. **Open the app** - Navigate to the web interface
2. **Paste a URL** - Enter your long URL in the input field
3. **Click "Shorten URL"** - Wait for your shortened URL to be generated
4. **Copy the link** - Use the copy button to get the shortened URL
5. **Share it** - Your shortened URL is now ready to share!

## Features Explained

### URL Shortening
- Uses 7-character unique IDs generated by `nanoid`
- Extremely low collision probability
- URLs are stored in memory (perfect for demos/prototypes)

### Click Tracking
- Each URL tracks how many times it's been visited
- Increments on each redirect
- Display click count in the admin interface

### Responsive Design
- Mobile-first approach
- Adapts to screens from 320px to 4K
- Touch-friendly buttons and inputs

## Data Storage

Currently uses **in-memory storage** (Map), meaning:
- ✅ Data persists during the session
- ❌ Data is lost when the server restarts
- ⚠️ Not suitable for production

### To add persistence:

1. **MongoDB:**
   ```javascript
   const urlSchema = new Schema({
     shortId: String,
     longUrl: String,
     createdAt: Date,
     clicks: Number
   })
   ```

2. **PostgreSQL:**
   ```sql
   CREATE TABLE urls (
     id SERIAL PRIMARY KEY,
     short_id VARCHAR(10) UNIQUE,
     long_url TEXT,
     created_at TIMESTAMP,
     clicks INT DEFAULT 0
   )
   ```

3. **Redis:**
   - Fast in-memory database with persistence options
   - Perfect for URL shorteners
